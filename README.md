Это ПО генерирует вариант задания по введённой дате рождения.

Есть два варианта работы с этим приложением:

1. В первом варианте можно использовать два способа:  
   Способ А:  
   A.1) Скачать архив с исполняемым файлом и иконкой (воспользуйтесь L-a-s-k-a/App-for-Task -> Releases -> CoV)  
   A.2) Разархивировать исполняемый файл и иконку, либо запустить исполняемый файл внутри архива  
   A.3) Ввести дату рождения в поле ввода, используя подсказки  
   A.4) Получить варинат задания  
  
   Способ Б:  
   Б.1) Скачать архив с собранным проектом (воспользуйтесь L-a-s-k-a/App-for-Task -> Releases -> CoV_app)  
   Б.2) Разархивировать исполняемый всё содержимое в какойнибудь каталог, либо запустить исполняемый файл внутри архива  
   Б.3) Ввести дату рождения в поле ввода, используя подсказки  
   Б.4) Получить варинат задания  
  
2. Можете скачать файл CoV.py и собрать приложение самостоятельно, для этого вам потребуется настроенная IDE
