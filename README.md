Это ПО генерирует вариант задания по введённой дате рождения.
Есть два варианта работы с этим приложением:
1) Вы можете скачать ПО в виде исполняемого файла, запустить его на своём компьютере, ввести дату рождения и получить задание
2) Можете скачать файл App_For_Task.py и собрать приложение самостоятельно, для этого вам потребуется настроенная IDE
